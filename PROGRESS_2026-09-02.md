## Đã Hoàn Thành

### Môi trường

- Tạo backend virtualenv bằng Python 3.10.
- Cài backend dependencies từ `backend/requirements.txt`.
- Cài dependencies frontend admin bằng lockfile.
- Cài dependencies mobile bằng lockfile.
- Cài PostgreSQL 16 native và xác nhận service `postgresql-x64-16` đang chạy.
- Tạo database test riêng `ecoloop_campus_test`.
- Tạo role test riêng `ecoloop_test`.
- Không xóa hoặc sửa database ứng dụng hiện có.

### PostgreSQL Schema Và Transaction

- Thêm bảng `reward_redemption_batches` cho một mã QR đổi thưởng.
- Thêm bảng `reward_redemption_items` cho nhiều sản phẩm/số lượng trong một batch.
- Thêm bảng `ai_training_samples` cho ảnh và nhãn AI đã được review.
- Thêm `rewards.stock`.
- Thêm `point_history.reference_type` và `point_history.reference_id`.
- Thêm PostgreSQL function `create_reward_redemption_batch`.
- Thêm PostgreSQL function `scan_reward_redemption_batch`.
- Thêm PostgreSQL function `finalize_reward_redemption_batch`.
- Thêm PostgreSQL function `adjust_manual_points`.
- Redemption QR có thời hạn 15 phút.
- Student chỉ có một redemption batch active.
- Tạo redemption batch chưa trừ điểm.
- Scan redemption hợp lệ mới khóa điểm, trừ điểm và giảm tồn kho.
- Fulfill không trừ thêm điểm.
- Reject/cancel sau scan hoàn điểm đúng một lần.
- QR hết hạn trước scan không làm thay đổi điểm.
- Chặn reward item trùng trong cùng batch.
- Cho phép xóa catalog reward mà vẫn giữ snapshot lịch sử batch bằng `ON DELETE SET NULL`.
- Tự chuyển batch pending đã hết hạn sang `expired` trước khi tạo batch mới.
- Schema chạy với `ON_ERROR_STOP=1` lần đầu và nhiều lần lặp lại không lỗi.

### Backend API

- `POST /api/mobile/reward-redemptions`: tạo redemption batch.
- `POST /api/mobile/reward-redemptions/scan`: volunteer/admin scan redemption.
- `POST /api/admin/reward-redemption-batches/{batch_id}/finalize`: admin fulfill/reject/cancel.
- `GET /api/admin/reward-redemption-batches`: list batch kèm items.
- `POST /api/admin/point-adjustments`: manual point transaction thật.
- `PATCH /api/admin/feedback/{feedback_id}`: cập nhật trạng thái feedback bằng backend.
- `POST /api/admin/predictions/{prediction_id}/correct`: lưu AI correction và export ảnh reviewed.
- Bảo vệ avatar preset bằng authentication/admin authorization.
- Bảo vệ các endpoint AI bằng authentication.
- Job AI chỉ cho owner hoặc admin xem.
- Giới hạn upload mặc định 10 MB.
- Không còn CORS wildcard mặc định.
- Manual point dùng `FOR UPDATE`, chặn số dư âm và ghi audit history.
- Approval prediction dùng reference để chống cộng điểm lặp.

### Mobile

- Thêm `requestRewardBatch`.
- Chọn số lượng reward.
- Có thể thêm nhiều reward vào một cart trước khi tạo QR.
- Gộp thành một batch QR duy nhất.
- Hiển thị QR redemption.
- Countdown từ `expiresAt` server.
- Disable thao tác tạo mã mới khi còn batch active.
- Scanner nhận diện token `ECL-REWARD-*`.
- Scanner gọi API redemption scan riêng.
- Refresh dữ liệu sau scan.
- Hiển thị trạng thái pending/scanned/fulfilled/expired/cancelled.
- Không còn thông báo đổi thưởng thành công ngay khi mới tạo batch.
- Thêm style cho quantity picker.

### Web Admin

- Web service manual point gọi backend transaction thật.
- Web service list redemption batch.
- Web service finalize redemption batch.
- Hiển thị danh sách batch và item.
- Có nút Hoàn tất và Hoàn điểm cho batch đã scan.
- Feedback status update gọi PATCH backend.
- Có map picker trong `BinsPage`.
- Click map để đặt marker.
- Kéo marker để thay đổi `mapX/mapY`.
- Giữ input tọa độ thủ công.
- Giới hạn tọa độ về 0-100.
- Có giao diện nhập nhãn AI đúng và nút review/export dataset trong `ScansPage`.
